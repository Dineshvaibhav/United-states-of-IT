Steps to contribute:

1. *Fork the repo* to your GitHub account
2. *Clone it locally* and open the project
3. *Add your name* to `sample.txt` 
4. *Commit your changes* using git:
   git add sample.txt
   git commit -m "Added <your-name> to sample.txt"
   git push origin main
5. *Create a Pull Request* from your fork to the main repo
